# JOFP/1.0

JOFP is the JSL Omega Field Protocol.

Core route:

`Device -> Register -> Normalize -> J(x,y,z) -> Omega Field`

Alpha endpoints:

- `/health`
- `/register`
- `/heartbeat`
- `/nodes`
- `/pair`
- `/send`
- `/receive`
- `/delivered`
- `/field`

This package is an Alpha test network, not a production-audited consensus system.
