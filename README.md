# JSL Omega Network

Complete GitHub deployment package for JOFP/1.0.

- Repository: `jsl-omega-network`
- Cloudflare project: `jsl-omega-network`
- D1 database: `jsl_omega_network`
- Public domain: `jofp.jsl-ian.com`
- Protocol: `JOFP/1.0`

Replace the D1 UUID in `wrangler.toml` before deployment.
